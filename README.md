# Gym-AI-Planner
This project is a production-ready AI Gym Planner application built with the PERN stack (PostgreSQL, Express, React, Node.js), designed to provide a cohesive, end-to-end full-stack experience.

Inspired by the need to bridge the gap between simple chat demos and robust production applications, this project focuses on system architecture and data-driven user experiences. It enables users to generate highly personalized workout plans through an interactive onboarding flow, with results powered by OpenAI models integrated via OpenRouter.

Key technical features:

Full-stack Integration: Seamless connectivity between a React frontend, Express backend, and a Neon PostgreSQL database.
Modern Authentication: Secure user management and protected routing implemented via Neon Auth.
Data-Driven AI: Dynamic AI-generated fitness content based on user-specific constraints and goals.
Interactive UI: A responsive, clean interface built with Tailwind CSS that supports real-time loading states and plan regeneration logic.
Modular Architecture: Component-driven development with reusable UI patterns, ensuring clean code, scalability, and an intuitive user journey.
